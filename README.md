# Cây Kí Ức

Website tĩnh gồm bốn cây tri ân, mỗi cây có một mã truy cập. Mã quản lý mở trang đăng ảnh lớp và sửa nội dung.

- Mở `public/index.html` để xem trên máy.
- Trên Vercel, nhập repo với **Root Directory** là thư mục gốc. `vercel.json` đặt thư mục xuất bản là `public`.
- Xem [hướng dẫn quản lý ảnh và dữ liệu](HUONG-DAN.md). Ảnh đã tải lên được lưu trong Supabase.
